# Command Line Interface (CLI)

Aflevering til modulet *Command Line Interface (CLI)* i WS1.

## Indhold
- `Screenshots/` – screenshots af alle opgaver
  - `Opgave1_trin1-10_grundlaeggende_CLI.png` – oprette, flytte, kopiere og slette filer og mapper
  - `Opgave2_trin1-5_java_i_CLI.png` – kompilere og køre `CliDemo.java` med `javac`/`java`, med og uden argumenter
  - `Opgave3_trin1-5_git_via_CLI.png` – clone, mappe `Screenshots`, flyt screenshots, commit og push
  - `Opgave3_commit_og_push_af_egne_screenshots.png` – commit og push af screenshots fra Opgave 3
- `Modul - CLI/` – mappen fra Opgave 1 og 2 som den så ud bagefter
  (`Archieve/` er tom efter trin 10. `.gitkeep` er kun med, fordi git ikke gemmer tomme mapper)

## Bemærkning
Kommandoerne er kørt i bash (Linux) i stedet for PowerShell. Kommandoerne svarer til hinanden:
`mkdir`, `cd`, `echo ... >`, `cat`, `mv`, `cp`, `rm` og `ls` virker også i PowerShell som aliaser.
I Opgave 2 blev `CliDemo.java` downloadet og kopieret ind, som opgaven tillader, i stedet for at bruge `curl`.
